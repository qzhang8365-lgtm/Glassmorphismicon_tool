# 磨砂玻璃 Icon 制作工具

纯静态单页面工具。样式、图案、图片和 JSZip 已内嵌在 index.html 中。

## GitHub

将本目录内容上传到仓库根目录即可。无需上传源参考目录、临时文件或之前各版本的产出。

## Netlify

方式一：将本目录拖入 Netlify Drop。

方式二：在 Netlify 导入 GitHub 仓库。若本目录内容位于仓库根目录，Build command 留空，Publish directory 填 `.`；若使用子目录，Publish directory 填实际目录路径。无需安装依赖、环境变量或后端。

## 使用限制

建议使用较新版本 Chrome、Edge 或 Safari。暂存作品只存在当前页面，刷新或关闭前请导出。上传文件在浏览器内处理，不通过本工具发送到服务器。SVG/PNG 与 ZIP 由浏览器生成并下载。
